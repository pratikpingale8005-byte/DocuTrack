DocuTrack

Terms & Conditions

DocuTrack is a college project. It is not a commercial service, and these terms do not promise uptime, backup, or a security certification.

Use

Use the account created for this project. Do not upload a file unless you are allowed to store it and share it.

What the actions do

  • Upload stores the file on the server. Uploading the same file name again creates the next version number on the server.
  • Delete marks your file as deleted. Restore clears that mark.
  • Share gives the user id you enter the permission you select.
  • A shared file with view permission cannot be downloaded. Download is allowed for download and edit permissions.
  • Transfer ownership changes the owner of the file to the user id you enter.
  • Run Retention Check applies the retention policy already stored for each expired file. That can flag the file, create a notification alert, or soft-delete it.

Information

Counts on the dashboard come from the files, shares, and alerts returned for the logged-in user. They are not estimates.
