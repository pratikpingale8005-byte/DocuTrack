DocuTrack

Privacy Policy

DocuTrack is a college project for storing and sharing documents. This page describes the data this project actually handles.

Account

Login sends your email and password to the DocuTrack server. The database stores the password as a hash. The server does not return the password.

A successful login returns a token and these fields: user id, name, email, role id, and department id. The browser stores the token and that user record in localStorage. The token expires after 1 hour.

Logout removes the token and user record from localStorage on this browser.

Files

Uploaded files are saved on the computer running the backend. The database stores the file name, extension, category, version, size, hash, owner, and timestamps.

Sharing stores the user id you enter and the permission you select: view, edit, or download.

Activity and alerts

Activity logs and alerts shown in the app are the records stored for the logged-in user.

What this project does not do

The frontend does not send data to a separate analytics service. This page does not claim compliance with a named privacy law.

What you should know

  • JavaScript on this site can read the token stored in localStorage.
  • Files remain on the backend machine until the project data is deleted there.
  • A retention check can soft-delete a file or create an alert when that file's stored policy says to do so.
